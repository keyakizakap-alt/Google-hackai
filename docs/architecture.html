HUMAN-IN-THE-LOOP GATE — stateMachine.ts

pending_approval→ approved→ booking→ booked ／rejected→revising
  • 赤枠の状態へはユーザー操作でしか進めない（エージェント・システムは不可）
  • 承認を経由しない経路が無いことをテストで遷移グラフを探索して確認
  • 予約はデモ予約（実在の店舗には届かない）・決済はしない、と画面に明記
  • 見張りが作る見直し案も、新しい承認待ちで止まる（今のプラン・予約は変えない）
