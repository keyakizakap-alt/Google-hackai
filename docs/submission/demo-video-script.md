# デモ動画の台本（約 3 分）

YouTube に公開し、URL をダッシュボードに登録する。審査の 3 つの基準（課題と有効性／自律性とその管理／実装品質）が 3 分で伝わる順に並べている。

## 撮影の準備

- **公開した Cloud Run の URL で撮る**（ローカルではなく、審査員が触るものと同じもの）
- シークレットウィンドウ、ブラウザの幅 1440px 前後、拡大率 100%。ブックマークバーと拡張機能のアイコンは隠す
- 推しカラーは 1 色に決めておく（途中で変えるなら 0:30 の場面で）
- **AI の待ち時間は編集で詰める**（「AI が調べたこと」が流れる部分は 2〜4 倍速にし、画面に「早送り」と出す）
- ナレーションは 1 分あたり約 300 字のペース。下の台本は合計約 900 字
- 録画は macOS なら「画面収録」（Shift + Command + 5）、Windows なら「Xbox Game Bar」か Clipchamp。字幕は YouTube Studio の自動字幕を直して付けると見やすい
- 架空のアーティスト名だけが映ることを確認する（自分のカレンダーや通知を映さない）

## 台本

| 時間 | 画面 | ナレーション |
|---|---|---|
| 0:00–0:20 | タイトル（アプリのホーム、またはアーキテクチャ図の上部）| 推しのライブの日が決まったら、その日に最高の状態で会場に立ちたい。でも、美容院、ネイル、移動、宿。仕事の合間を縫って、最適な日を探すのは大変です。OshiReady は、ライブの日から準備を逆算する AI エージェントです。 |
| 0:20–0:40 | ホームで「デモのカレンダーで試す」を押す → ライブが自動で登録される | カレンダーを連携すると、予定の中からライブを見つけて登録します。今日は架空のライブが入ったデモのカレンダーを使います。チケットのスクリーンショットから読み取ることもできます。 |
| 0:40–1:20 | ライブを選ぶ → プランが作られる → 「AI が調べたこと」を開く（早送り）| ライブを選ぶと、エージェントが自分で調べ始めます。空き時間、美容の最適なタイミング、施術の候補日時、会場周辺の混雑、公演日の天気、乗り換え、そして Google 検索で実在のお店や飛行機の便。どの道具をどの順で使うかは、エージェントが状況を見て決めます。ここを見てください。提出したプランが検証で差し戻され、エージェントが自分で直して出し直しています。 |
| 1:20–1:45 | 完成したタイムラインをスクロール（「Google 検索の出典」の札と、下の「Google 検索で調べたこと」を映す）| ヘアは数日なじませたいので 2〜5 日前、ネイルは欠けないように直前の 1〜3 日前。遠征なら新幹線と飛行機を比べて、間に合う便を選びます。お店や便は Google 検索で見つけたものだけを、出典つきで出します。検索結果にない名前や価格は、検査で差し戻します。 |
| 1:45–2:05 | 入力欄に「ネイルは土曜日にしたい」と入れて送信 → 作り直したプラン | 修正は、言葉で伝えるだけ。作り直したプランも、もう一度承認待ちに戻ります。 |
| 2:05–2:30 | 「確認して承認する」→ 項目の「予約する」→「予約の管理」（デモ予約の表示を映す）| ここが大事なところです。AI は予約できません。予約に進めるのは、あなたが承認し、「予約する」を押したものだけです。今回はデモ予約なので、実在のお店には届きません。 |
| 2:30–2:45 | ナビの「プラン」で一覧を開く → 見直し案の通知（カレンダーに予定を追加した後の状態）、または設定の「AI ができること・できないこと」| ライブごとのプランは一覧でまとめて見られます。承認した後も、エージェントはカレンダーの変化や天気を見張ります。困ることが見つかれば見直し案を作りますが、切り替えるかどうかは、あなたが決めます。 |
| 2:45–3:00 | アーキテクチャ図（全体 → 下の GUARDRAILS 帯）| Cloud Run と Gemini で動き、予約はユーザーの操作でしか進まない仕組み、攻撃文を使ったテスト、個人の予定を保存しない設計で、自律と安心を両立しました。推しに会う日を、いちばん気持ちよく。OshiReady でした。 |

## 2:30 の「見直し案」を撮るには

見直し案は、承認後にカレンダーへ予定が増えたときに出る。撮る場合は、デモのカレンダー（デモ用の Google アカウント）に、承認したプランの時間帯と重なる予定を 1 件足してからアプリに戻る（数分〜10 分ほどで見張りが検知する）。時間がなければ、この場面は設定画面の「AI ができること・できないこと」に差し替える。

## 公開前の確認

- [ ] 長さが 3 分前後（大きく超えない）
- [ ] 自分の個人情報（本名・メールアドレス・実在の予定・通知）が映っていない
- [ ] 「デモ予約で実在の店舗には届かない」ことが画面かナレーションで伝わる
- [ ] Google 検索の出典の札・「検索時点の参考」の表示が映る（空席は未確認であることが伝わる）
- [ ] BGM を使うなら、YouTube オーディオライブラリなど利用条件が明確なものにする
- [ ] YouTube の公開範囲（公開／限定公開）が規約の条件を満たすか、公式ページで確認した
