# 動作確認の方法（ダッシュボード用の下書き）

ダッシュボードの「動作確認の方法」に貼る文章。URL は公開中の Cloud Run（サービス名 `google-hackai`）。
貼る前に、公開した URL で下の手順をシークレットウィンドウから通しで確認する。

---

**ログイン・アカウント作成・メールの受信は不要です。** パソコンのブラウザ（Chrome 推奨）でもスマートフォンでも試せます。

1. https://google-hackai-791850738177.asia-northeast1.run.app を開きます（しばらく使われていないと、最初の表示に数秒かかることがあります）
2. ホームの **「デモのカレンダーで試す」** を押します。架空のライブの予定が入ったデモ用の Google カレンダーを読み込み、ライブが自動で登録されます
3. ライブを 1 つ選ぶと、AI エージェントが準備プランを作り始めます（30 秒〜1 分ほど）。**「AI が調べたこと」** で、エージェントが使った道具、検証で差し戻されて自分で組み直した流れ、所要時間を確認できます。遠征のライブでは、Google 検索で見つけたサロン・便に **「Google 検索の出典」** の札と検索時点の参考価格が付き、プランの下の **「Google 検索で調べたこと」** で出典を確認できます（空席・空室は Google フライトや予約サイトのリンクで確かめる形です）
4. 下の入力欄から、修正の指示を送れます（例：「ネイルは土曜日にしたい」「雨のときの準備も入れて」）。作り直したプランも承認待ちに戻ります
5. **「確認して承認する」** で承認し、項目の **「予約する」** を押すと予約されます。**これはデモ予約で、実在の店舗には届きません。** 支払いも発生しません
6. **「予約の管理」** から予約を確認し、**「キャンセルを確定する」** で取り消せます
7. ナビの **「プラン」** を開くと、ライブごとのプランの一覧（承認待ち・承認済み・予約済み・未作成）が表示され、そこから各ライブのプランを開けます
8. 設定画面の **「AI ができること・できないこと」** で、AI に任せている範囲と、ユーザーにしかできない操作を確認できます

**補足**

- デモのデータはすべて架空です（アーティスト名・予定）。会場名は実在の施設名を、最寄り駅の案内のためにだけ使っています
- 入力した内容や予約のメモは、お使いのブラウザの中にだけ保存されます。設定画面の「デモをやめる」で元に戻せます
- AI の呼び出しには 1 日の上限があります。上限に達した場合は時間をおいて試してください
- ご自身の Google カレンダーと連携する場合は「Google で連携する」から試せます（読み取り専用。同意画面が「テスト」状態のため、許可した利用者以外は連携できない場合があります）
